# 🌰 도토리 산행 정산

산행 모임의 **카풀 유류비 · 수고비 · 렌트비 · 공동 경비**를 자동 계산해 인원별로 정리해주는 웹 앱입니다.

🔗 **라이브**: [https://bgjoe40.github.io/dotori/](https://bgjoe40.github.io/dotori/)

---

## 주요 기능

| 탭 | 기능 |
|---|---|
| 🚗 카풀 | 차량별 거리·톨비·주차비·수고비 입력 → 1인당 유류비·수고비 자동 계산 |
| 🚐 렌트 | 렌트비·수고비 입력 → 탑승자/운전자 부담액 자동 계산 |
| 🧾 경비 | N빵 / 인원추가 방식으로 공동 경비 항목 추가 |
| 💰 최종 정산 | 카풀·렌트·경비 통합 → 벙주 기준 수금·지급 내역 정리 |

- **벙주(총무) 중심 2단계 정산**: 모든 참가자 → 벙주 수금 → 벙주 → 운전자/지출자 지급
- **아코디언 내역**: 참가자별 클릭으로 세부 항목 확인
- **공유 텍스트 복사**: 카카오톡·문자에 붙여넣기 가능
- **다크모드** 지원
- **브라우저 자동 저장** (localStorage, 서버 불필요)
- **JSON 백업 / 복원 / 초기화**

## 정산 계산 방식

### 유류비
```
1인당 유류비 = (왕복거리 × 유류비단가 + 톨비 + 주차비) ÷ 카풀참가자수
```
- 기본 단가: **170원/km**
- 운전자 포함 전체 카풀 참가자 균등 분담

### 수고비
```
1인당 수고비 = 총수고비 ÷ 탑승자수 (운전자 제외)
```

### 경비 (N빵)
```
1인당 = round(총액 ÷ 참여인원)
```

### 경비 (인원추가)
```
총액 = 1인당금액 × 참여인원
```
